# Baraka School Kapsabet Frontend  

## 📚 Project Overview  
A modern React/Vite application for Baraka School Kapsabet, featuring:  
- Custom CSS design system  
- Dark mode support  
- Scroll animations  
- Responsive layouts  
- Accessibility-first components  

## 🛠️ Local Setup  
1. **Install dependencies**  
   ```bash  
   npm install  
   ```  

2. **Start development server**  
   ```bash  
   npm run dev  
   ```  

3. **Build for production**  
   ```bash  
   npm run build  
   ```  

## 📝 Contributing Guidelines  
- Follow the [Airbnb JavaScript Style Guide](https://github.com/airbnb/javascript)  
- All components must be under 100 lines  
- Use `useTheme` hook for dark mode  
- Add tests for new components  
- Update `sitemap.xml` for new pages

## 📌 Environment Variables  
Create `.env.example` with:  
```  
VITE_API_BASE_URL=/api  
VITE_APP_NAME=Baraka School Kapsabet  
```
